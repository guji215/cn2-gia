## 搬瓦工购买流程：从下单到支付宝到账

整个购买分四步：选套餐进购物车、填注册信息、确认订单、扫码付款。

**第一步，选套餐和配置。** 进套餐页后购物车要确认两个选项。计费周期按套餐实际情况选，20G 只有年付这一档；机房位置方面，通用 KVM 套餐有十几个数据中心可选，覆盖美西、美东、欧洲、加拿大、荷兰，洛杉矶机房到国内的表现通常好一些。

**第二步，注册账户。** 新手最容易出错的地方在这里，几条填写要点：

1. 国家一栏必须选中国，省市按真实情况填；
2. 邮箱填能正常收信的——邮箱就是以后的登录名，填错后面很麻烦；
3. 密码设强一点，大小写、数字、符号都用上；
4. 服务条款前的勾必须勾上，否则订单提交不了。

**第三步，确认订单。** 结账页有 Validate Code 输入位，有可用优惠码就在这里填，确认总价无误后提交。

**第四步，付款。** 支付方式里选 Alipay，点 Complete Order 跳出二维码，手机扫码支付即可。银联、PayPal 和信用卡也都支持。付款成功后 VPS 即时开通，登录 KiwiVM 后台就能看到机器，注册邮箱会同步收到确认邮件。
